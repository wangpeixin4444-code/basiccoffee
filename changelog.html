更新日志

这个站点是怎么一步步改过来的。早期版本按功能编号，近期版本按修复批次记录——包括改错过什么、为什么改。

v2.1.1 · 2026-09-29
不蒜子计数器位置修正：v2.1 的访客统计插入位置错误——落在了 </footer> 之外的浅色背景区，奶油色文字隐形。已把它移回 footer 深色容器内部，版权行下方终于能看到一行淡色的「☕ 本站访客数 X · 今日 Y」。

v2.1 · 2026-09-29
全站接入访客计数器（不蒜子）：每个页面底部 footer 都嵌入一行轻巧的访客统计——「☕ 本站访客数 X · 今日 Y」。基于国内通用的不蒜子服务，零注册、零配置、加载快；用 font-variant-numeric: tabular-nums 让数字等宽（跳动时不左右晃）；异步加载并带 1.2s 兜底检查，被墙时不会留破图，只显示「计算中…」。这是站点开放以来的第一个数据反馈。

v2.0.3 · 2026-09-29
烘焙页两项可用性修复：① 烘焙度对比表的第一列字色原写死为深棕色（浅底表格用），但烘焙页这张是深底表格——「浅烘/中烘/深烘」几乎看不见。已为该表新增 .on-dark 类把第一列改为奶油色；② 烘焙页的 3 张示意图（温度曲线、豆色对比、烘焙机结构）原本用固定宽高比 + object-fit: cover，左右和底部的标注被裁切掉。已让它们改为完整显示（aspect-ratio: auto + object-fit: contain），边缘文字和坐标轴不再丢失。

v2.0.2 fix · 2026-09-29
导航居中真正生效：v2.0.2 的对称居中布局其实从未真正生效——居中脚本里残留了一行 if (flavor) center(flavor)，但变量已重命名为 home，未声明的变量导致整段脚本直接报错，导航一直停在最左端。已修正变量名（7 个页面统一），并叠加 document.fonts.ready + window.load 二次校准——进入任何页面，「首页」都会准确滑到导航栏正中央，与设计图完全一致。

v2.0.2 · 2026-09-28
导航栏居中对称设计：顶部导航改为上下两层居中布局：品牌名「咖啡科普小站」居于第 1 行（页面水平中心），滑动导航居于第 2 行（也严格居中）——整体在页面中轴线上完全对称；导航顺序为「风味 → 处理法 → 烘焙 → 首页 → 豆种 → 冲泡 → 产区」，首页天然处在第 4 位（正中）；左滑可看到风味，右滑可依次展开豆种/冲泡/产区，视野始终保持 5 个入口；若当前页面链接在视野外（如产区页），会自动改为居中该链接，不会“迷路”。

v2.0.1 · 2026-09-24
导航与文案收尾：顶部导航栏改为可横向滑动式（桌面端与移动端均支持，scrollbar 细化为 4px 高度、深色描边色 hover 加深），7 个链接不再撑爆容器；章号措辞统一为「六个章节」（首页 hero-meta、EXPLORE eyebrow、首页/各页 footer 同步）；4 个子页（flavor/varieties/brewing/origins）的面包屑章号同步到新编号；README.md 同步 6 章结构并移除明文手机号（隐私升级）。

新增第二章「烘焙」：从生豆到棕褐色成品豆的化学反应全解——美拉德反应（核心）+ 焦糖化（中等）+ 斯特雷克降解（一段简提），三反应讲到“骨架感”的化学来源；烘焙度光谱（浅 / 中 / 深）× 风味特征对比表；一爆二爆；直火 / 热风 / 半热风三流派对比；烘焙曲线 / RoR / DTR 一段讲清楚；包装选购避坑贴士。
