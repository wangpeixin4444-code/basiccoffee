# ☕ 咖啡科普小站

一个面向咖啡初学者的入门级科普站，专注三件最影响咖啡风味的事：

- **处理法** · 一颗果实如何变成一颗生豆
- **风味** · 你在杯中喝到了什么
- **豆种** · 这一切的基因起点

## 🌐 站点结构

| 页面 | 内容 | 路径 |
|---|---|---|
| 主页 | 三个章节入口卡片 + 关于本站 + 联系作者 | `index.html` |
| 第一章 | 6 种主流处理法 + 7 种小众处理法详解 | `processing.html` |
| 第二章 | 风味入门（基础味觉、SCA 风味轮） | `flavor.html` |
| 第三章 | 豆种入门（三大原生种 + 主流变种） | `varieties.html` |

## 🛠️ 技术栈

- 纯静态 HTML + Tailwind CSS（CDN 引入）
- 自托管样式：`assets/style.css`
- 零 JavaScript、零后端
- 部署目标：Cloudflare Pages
