# ☕ 咖啡科普小站

一个面向咖啡初学者的入门级科普站，覆盖从生豆到一杯咖啡的全工艺链：

- **处理法** · 一颗果实如何变成一颗生豆
- **烘焙** · 12 分钟的化学反应秀（美拉德 / 焦糖化）
- **风味** · 你在杯中喝到了什么
- **豆种** · 这一切的基因起点
- **冲泡** · 同一种豆七种冲法七种味道
- **产区** · 海拔与气候如何塑造"地理指纹"

## 🌐 站点结构

| 页面 | 内容 | 路径 |
|---|---|---|
| 主页 | 六个章节入口卡片 + 关于本站 + 联系作者 | `index.html` |
| 第一章 · 处理法 | 6 种主流处理法 + 7 种小众处理法详解 | `processing.html` |
| 第二章 · 烘焙 | 美拉德 / 焦糖化 / 一爆二爆 / 烘焙度 / 设备流派 / 烘焙曲线 | `roasting.html` |
| 第三章 · 风味 | 基础味觉、SCA 风味轮、风味识别框架 | `flavor.html` |
| 第四章 · 豆种 | 三大原生种 + 阿拉比卡下属变种 | `varieties.html` |
| 第五章 · 冲泡 | 手冲 / 法压 / 意式 / Moka / 虹吸 / 冰滴 / 爱乐压 | `brewing.html` |
| 第六章 · 产区 | 非洲 / 拉美 / 亚洲三大产区风土差异 | `origins.html` |

## 🛠️ 技术栈

- 纯静态 HTML + Tailwind CSS（CDN 引入）
- 自托管样式：`assets/style.css`
- 零 JavaScript、零后端
- 部署目标：Cloudflare Pages / GitHub Pages
- 评论系统：Giscus（基于 GitHub Discussions）
- SEO：`sitemap.xml` + `robots.txt` + canonical + OG / Twitter Card
